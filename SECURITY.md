# Security policy

Report vulnerabilities privately to security@mirrorz.app. We acknowledge within 2 business days and aim to ship fixes for licensing, remote-pairing, or sandbox-escape issues within 14 days. Please do not open public issues for security reports.

Scope: the macOS app, companions, the licensing/remote service (`server/`), and the Rust core. Bundled third-party engines (QEMU, Wine, DXMT, MoltenVK) should be reported upstream as well.
